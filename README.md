# 🎮 C-XO Game

A simple Tic-Tac-Toe (C-XO) game developed using C++.

## 📌 About the Project

This project is a C++ implementation of the classic C-XO game.
The project was created as a programming practice project.

## ✨ Features

- Two-player gameplay
- Simple and easy-to-use interface
- Written in C++
- Console-based game

## 🛠️ Technologies Used

- C++
- Code::Blocks

## 🚀 How to Run

1. Download or clone this repository.
2. Open `xo.cbp` using Code::Blocks.
3. Build and run the project.
4. Enjoy the game! 🎮
